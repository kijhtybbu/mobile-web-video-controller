# 移动端网页视频播放控制器 (Mobile Web Video Controller)

专为安卓端移动浏览器（Via、X 浏览器、Kiwi、Firefox Mobile、Lemur 等）打造的通用网页视频控制脚本。为所有网页播放器带来媲美原生客户端的快进、快退与长按倍速体验。

---

## ✨ 核心特性

- ⏩ **双向 ±15 秒精准快进/快退**：
  - **屏幕双击**：双击视频左侧区域后退 15s，双击右侧区域前进 15s。
  - **大号悬浮按钮**：点击唤出 60px 半透明磨砂质感 `-15` 和 `+15` 纯文本按钮，触控更直观。
- ⚡ **按住 2 倍速快进**：
  - 在右侧区域或 `+15` 按钮上**长按超过 350ms**，自动激活 **2.0X 倍速快进**，顶部伴随黄色 HUD 提示。
  - **松开手指即刻恢复原速**，且智能抑制单次快进跳转。
- 🛡️ **防误触 & 绝不遮挡原生进度条**：
  - 响应高度限定为中间 **55%** 垂直居中，顶部标题栏与底部进度条区域（各占约 22.5%）完全透传，拖拽进度条毫无阻隔。
  - 中央 30% 区域彻底穿透，不影响原生暂停、清晰度选择等菜单。
- 🔒 **严格事件隔离（防双击全屏/暂停误触）**：
  - 彻底拦截冒泡，解决移动端双击悬浮按钮事件外泄被原生播放器当成暂停或全屏手势的顽疾。
- 📱 **Shadow DOM & 全屏自适应**：
  - 样式与宿主页面 100% 隔离，绝不破坏页面样式；支持全屏模式自动挂载重定位，单页应用（SPA）动态加载视频即插即用。

## 🚀 安装方法

### 方式一：一键在线安装（推荐）

在支持油猴脚本的移动浏览器中点击下方链接即可调起安装界面：

👉 **[点击直接安装脚本 (Install)](https://raw.githubusercontent.com/kijhtybbu/mobile-web-video-controller/master/video-seek-15s.user.js)**

---

### 方式二：手动导入

#### 1. Via 浏览器 / X 浏览器
1. 打开浏览器设置 ->「脚本代码」或「用户脚本」管理。
2. 点击「新建脚本」。
3. 将 [video-seek-15s.user.js](https://raw.githubusercontent.com/kijhtybbu/mobile-web-video-controller/master/video-seek-15s.user.js) 的代码全部复制并粘贴进去。
4. 域名匹配填写 `*`，保存并启用。

#### 2. Kiwi / Firefox Mobile / Lemur 浏览器
1. 安装扩展 **Tampermonkey** 或 **Violentmonkey**。
2. 打开扩展控制面板，点击「添加新脚本」。
3. 粘贴 [video-seek-15s.user.js](https://raw.githubusercontent.com/kijhtybbu/mobile-web-video-controller/master/video-seek-15s.user.js) 代码，快捷键保存（Ctrl+S 或点击保存）。

## ⚙️ 常见配置项自定义

若希望微调秒数或延迟，可直接编辑脚本前部的常量配置：

```javascript
const SEEK_STEP = 15;        // 每次跳转的秒数（默认 15 秒）
const DOUBLE_TAP_DELAY = 300; // 双击判定的时间窗口 (毫秒)
const AUTO_HIDE_DELAY = 3000; // 悬浮按钮无操作自动隐藏时间 (毫秒)
const LONG_PRESS_DELAY = 350; // 长按触发 2 倍速的阈值 (毫秒)
```
